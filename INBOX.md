# Inbox

Anything that arrives mid-thought goes here first, dated, one line. Nothing is lost and
nothing has to be filed at the moment it occurs to you.

Process it when you choose to, not when it arrives. Each line ends in one of four places:

- **Do it** — it takes under two minutes, so it never needed a note.
- **Move it** — it belongs in [`ROADMAP.md`](ROADMAP.md) or a reference doc. Cut, paste, delete the line here.
- **Decide it** — it's a question, not a task. Write the decision into [`SESSION_LOG.md`](SESSION_LOG.md) so the next session doesn't re-open it.
- **Bin it** — most things. Deleting a line here is a legitimate outcome, not a failure.

An item with no date is an item you can't triage later, so date every line.
